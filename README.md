# 五界生物研究餐廳 Biology Dining Lab

完整本機整合版：日系研究餐廳、橢圓巡遊餐盤、48 種獨立生物插畫，搭配原題庫 36 張研究委託。

## 開啟

以瀏覽器開啟 index.html 即可離線遊玩。HTTP / GitHub Pages 下優先讀取 data 內四份主題庫，逾時或資料不完整則使用 data-embedded.js 的完整備用資料。上傳時須保留 assets、data 與所有 HTML、CSS、JS。本次只整合本機，未推送或部署。

## 保留的遊戲規則

- 微觀奇兵、植感大餐、動物派對各抽 6 張基礎、3 張挑戰；五界混合則三單元各抽 2 張基礎、1 張挑戰。
- 每局 9 張不重複委託，同時顯示 3 張。每張需正確提交 2 次，可重複取用同種生物。
- 工作台容量 7 格。答錯保留樣本、連擊歸零；更新餐桌不限次且不扣分。
- 每次正確 15 分起，連擊每次額外加 3 分，最多額外 15 分；完成委託再加 50 分。
- 金幣每次正確 5、每張完成 20；十八次連續正確共 945 分、270 金幣。
- 原 JSON 的 acceptedSpecies、explanation、source 與分類資料未改動。

## 操作與功能

選委託 → 點餐盤觀察 → 取樣至工作台 → 選取樣本 → 送交鑑定。

陪伴練習直接顯示特徵；自主挑戰先隱藏，仍可主動查看或查圖鑑。滑鼠停留、鍵盤聚焦、對話窗與鑑定期間會暫停餐桌。可手動暫停，支援減少動態效果。

圖鑑支援五界篩選、名稱搜尋與分頁；查看時記錄「已觀察」，成功提交另記錄「已鑑定」。裝飾商店可購買、套用三種介面配色與三種盤緣樣式，已購買不重複扣款，不影響分類與計分。

結算包含提交正確率（含重試）、各委託首答正確率、查看線索次數、各單元表現、九張委託的解釋與題目來源。首答以每張委託的第一次提交計算；因允許圖鑑與提示，不代表封閉式測驗成績。

課堂計時器獨立運作，不會強制結束研究；音效可關閉。

## 存檔

localStorage 鍵 biology_dining_v5，一次保存金幣、最高分、收藏、裝飾、音效與未完成研究。返回入口或重新整理後可續玩；開始新研究前需確認重設本局。完成的局不會再次作為進行中局領獎。

首次載入承接 bio_sushi_v4 或 bio_lab_v3 中有效的金幣、最高分與收藏，保留原鍵。存檔限定同一瀏覽器與網址來源；file:// 儲存依瀏覽器而異，無跨裝置同步。儲存失敗時會提示。

## 維護與驗證

core.js 負責抽題、判定、計分、存檔驗證與商店；game.js 負責畫面、互動、圖鑑、音效、計時器與儲存。data-embedded.js 由四份主題庫產生，修改 JSON 後須同步重建。題庫皆收錄於 data 資料夾（biology.json 與三單元主題庫）。

執行 `node tests/regression.cjs`，不需 npm 安裝。已通過四主題共 480 局、8,640 次正確提交的核心測試；瀏覽器亦將四主題各完成一局，驗證答錯保留、滿盤限制、進度恢復、裝飾購買與重載、圖鑑搜尋、計時器及線上題庫缺失降級。桌機 1440×900、手機 390×844 檢查無文件橫向溢出；尚未使用實體手機驗收觸控與音效。

生物圖像為 AI 製作的形態示意，微生物已放大且非等比例，不應只靠圖像證明細胞構造。判定依原題庫文字與分類資料。素材索引與提示詞摘要見 ASSETS.md。
