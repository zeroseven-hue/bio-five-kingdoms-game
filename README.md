# 五界研究所 V4：主題菜單與均衡抽題

## 上傳 GitHub
解壓縮完整程式包，將 index.html、style.css、game.js、README.md 及 data 資料夾上傳。HTML/CSS/JS 同層，data 內保留四個 JSON。
開啟 GitHub Pages 網址，必要時 Ctrl+F5。不能直接雙擊 HTML，因為題庫需要 HTTP 載入。
程式無外部聲音、字型或圖片依賴。音效需學生第一次操作後才會播放；可關閉。

## 四種主題
- 微觀奇兵：原核、原生與真菌。
- 植感大餐：植物分類與特徵。
- 動物派對：動物分類與特徵。
- 混合大餐：三個單元平均抽取。

點主題卡後，按「開始這份研究」。改選主題卡只改下一局的選擇，不會立即打斷正在玩的研究。已有作答紀錄時開始新研究會要求確認；金幣、裝飾、圖鑑仍保留。

## 一局規則
每局 9 張委託，每張 2 次正確提交，共答對 18 次完成；答錯可重試，次數可能超過 18。
單一主題抽 6 張基礎、3 張挑戰。混合大餐每個單元抽 2 張基礎、1 張挑戰，共 9 張。
以 Fisher–Yates 洗牌後不放回抽取，整局名單先固定，不會補單後又抽到同一張。
不同委託可能都涉及同一種生物，但考的辨識重點不同。樣本卡可重複，下一局也可能遇到以前的委託；不保證跨局永不重複。
本版沒有逐關解鎖或計時壓力。完成後顯示提交正確率、得分與本局委託解說及原題號。

## 新題庫結構
原始三份四選一題庫未改寫；本包 data 中同名檔案是專為本遊戲改編的委託格式，請勿拿去覆蓋其他四選一遊戲的原題庫。
- biology.json：共享生物卡、線索、插圖設定。
- unit03_prokaryotes_protists_fungi.json：12 張微觀委託。
- unit04_plants.json：12 張植物委託。
- unit05_animals.json：12 張動物委託。

每張委託含 id、unit、concept、text、difficulty、acceptedSpecies、explanation、hint、source。source 保留原始檔名、題號、題幹；是內容改編，不是原題原選項直接搬進遊戲。
以 acceptedSpecies 的生物名稱名單判定；新增生物時，不會自動成為舊委託正解，需明確更新名單。委託描述「找出」代表找出現有樣本中的符合者。
每個單元至少保留 6 張基礎、3 張挑戰，且每張必須有有效生物答案。若檔案缺少或題庫不完整，畫面會提示載入失敗。
主題名稱位於 HTML 及 game.js 的 THEME_NAMES，可調整名稱但 unit 識別碼不變。

## 教學考量
保留依國中課堂五界分類。插圖為可愛辨識示意，不是精確形態或比例的顯微圖；判斷仍須依文字線索。
避免把跨界合成當成進化。避免只靠是否移動或名稱判斷。植物的葉綠體提示指光合部位，不是所有細胞。
原題中有重複題、較長的題幹、表格缺失或概念需要補充的題，未全部直接搬入。選用每單元 12 題的概念改寫，沒有把原 150 題宣稱全部納入。
本版有 36 張委託，不等同完整的課程評量。若用作診斷評量，挑戰模式仍允許查看線索，而且答題正確率含重試，不代表第一次作答正確率。

## 驗證
JavaScript 語法及 jsdom DOM 操作檢查通過：四種主題、抽題唯一性、混合比例與難度、500 次混合抽題、四主題各 18 次正確提交至結算、空席、錯誤保留、滿盤放回、重整、連點鎖定、主題切換與回顧。
本環境未完成實際瀏覽器的渲染、手機版面與音效聆聽驗收。上傳後請先以電腦與手機各試玩一次。

## 存檔
金幣、圖鑑、個人最佳及裝飾存於同一瀏覽器的 localStorage。本版沿用 bio_lab_v3 存檔鍵；清除瀏覽器資料後會消失，不跨裝置同步。無學生登入、全班排行榜或教師後台。
